# 과학 시뮬레이션 학습 허브 만들기

중·고등학생이 교과서 속 과학 원리를 **직접 만지며** 이해하도록, 외부 라이브러리 없이 동작하는
Canvas 시뮬레이션과 이를 모은 허브 페이지를 만든다. 핵심 가치는 **일관성**이다 — 모든
시뮬레이션이 같은 골격(허브 버튼·이론 팝업·정보 박스·반응형·글꼴)을 공유해야, 학생이 한 번
익히면 21개 어디서나 헤매지 않는다.

## 언제·어떻게 쓰나

- **시뮬레이션 1개 추가** → `assets/simulation-template.html`을 복사해 물리 로직만 갈아끼운다.
- **허브 페이지 제작/수정** → `references/hub-and-robot.md`의 허브 구조를 따른다.
- **마우스 따라오는 3D 로봇 배경** → 같은 레퍼런스의 "로봇 배경" 절을 따른다.

새 개념을 만들기 전에, 그 개념이 학생에게 **무엇을 보여줘야 직관이 생기는지**부터 정한다.
숫자 나열보다 그림·움직임·그래프가 우선이다(예: 옴의 법칙은 작은 글자 V·R·I 박스보다
"전류 0.71A = 전압 5V ÷ 저항 7Ω" 색상 수식 + 전류 게이지 막대가 훨씬 잘 와닿는다).

## 폴더 구조

```
science-simulation/
├── index.html                      # 허브 (카드 그리드 + 교과 배지)
├── fonts/
│   ├── Pretendard-Regular.otf
│   └── Pretendard-Medium.otf
├── projectile-motion-simulation/
│   └── index.html
├── energy-conservation-simulation/
│   └── index.html
└── ...                             # <개념>-simulation/index.html 패턴
```

- 시뮬레이션은 폰트를 `../fonts/`로, 허브는 `./fonts/`로 참조한다.
- 허브→시뮬레이션 링크는 `./<name>-simulation/index.html`, 시뮬레이션→허브는 `../index.html`.
- **링크 검증을 항상 한다.** 사용자가 "링크가 안 된다"고 했던 전례가 있다 — 경로(`./` vs `../`)와
  폴더명 철자를 만든 직후 확인한다.

## 시뮬레이션 한 개의 골격 (필수 규칙)

`assets/simulation-template.html`이 정본이다. 핵심 규칙:

1. **단일 HTML·무라이브러리.** `<canvas>` + 바닐라 JS. DPR 보정 리사이즈, `position:absolute; inset:0`
   전체화면 캔버스. 외부 CDN·프레임워크 금지(로봇 배경 예외는 허브 한정).
2. **좌상단 버튼 2개(고정, z-index:9999).**
   - `← 허브로` (`#backHub`, `top:14px; left:14px`) → `../index.html`
   - `📖 이론 배우기` (`#theoryBtn`, `top:14px; left:126px`) → 이론 팝업 열기
3. **정보 박스는 버튼을 절대 가리지 않는다.** 좌상단 버튼 영역(대략 `left:14~260px, top:14~52px`)을
   피해, 화면 **상단 중앙(py=58)** 또는 **하단**에 둔다. 이 규칙을 어겨 버튼이 막힌 적이 있다.
4. **이론 배우기 팝업.** 초등학생도 이해할 수준의 설명 + **그 시뮬레이션 사용 방법**을 담는다.
   `display:flex` 토글, 바깥 클릭·`Esc`로 닫기, 우상단 `×` 버튼. 구조는 템플릿의 `#theoryModal` 참고.
5. **컨트롤 패널.** 하단 중앙 `.panel`(blur 배경). 슬라이더·드롭다운·버튼으로 파라미터 조작.
6. **반응형/터치.** 뷰포트 확대 잠금(`maximum-scale=1.0, user-scalable=no`),
   `@media (pointer:coarse){ button{height:42px} ... }`, `overscroll-behavior:none`.
7. **Pretendard 글꼴.** 두 weight를 `@font-face`로 불러오고 `font-family` 스택 맨 앞에 둔다.
   캔버스 텍스트도 `ctx.font='... Pretendard, sans-serif'`.

## 허브 페이지 (요약 — 자세히는 레퍼런스)

- 어두운 라디얼 그라데이션 배경, 중앙 정렬 `.wrap`(max 1080px).
- 개념을 **카테고리 섹션**으로 묶는다(물리 / 화학 / 자연·창발 / 생물 / 천체·지구·카오스 등).
- 각 카드: 이모지 · 제목 · 한 줄 설명 · **교과 단원 배지**.
- 배지 3종: `basic`(중학 기초·초록) / `adv`(고등 심화·호박) / `fusion`(교과 밖·회청).
  문구는 학년+수준+단원: 예) `중2 기초 『전기와 자기』`, `물리학Ⅱ 『평면 운동』`. 중복 표시 가능.
- 상단 범례 + "2015·2022 개정 교육과정 기준의 대략적 위치" 안내 문구.
- 푸터에 피드백 연락처(이메일·오픈채팅 등)를 둔다.

자세한 마크업·배지 색·로봇 배경은 **`references/hub-and-robot.md`**를 읽고 따른다.

## 검증 (눈으로 확인할 수 없을 때)

미리보기가 백그라운드/헤드리스라 스크린샷이 안 잡히거나 WebGL·transition이 throttle될 수 있다.
그럴 때는 DOM/CSS를 직접 조사해 동작을 확정한다:

- 요소 존재·텍스트·개수(`querySelectorAll`), 계산된 색(`getComputedStyle`)으로 글꼴/색 적용 확인.
- 버튼-정보박스 겹침은 `getBoundingClientRect`로 좌표 비교.
- 로봇 배경의 마우스 통과는 `document.elementFromPoint(x,y)`가 빈 영역에서 `spline-viewer`를,
  카드 위에서 카드 링크를 반환하는지로 확인.
- 콘솔 에러 0 확인. 스크린샷이 막히면 "DOM 검사로 확정했고, 실제 브라우저에서 열면 보인다"고
  사용자에게 정직하게 알린다.

## 흔한 함정 (실제로 겪은 것들)

- **물리가 멈춤(v=0 잠김).** 정지점에서 다시 못 움직이면 미세 에너지를 주어 부트스트랩한다
  (예: 역학적 에너지 보존에서 경사 감지 후 작은 속도 부여).
- **글자 겹침.** 좌상단 정보 박스가 버튼과 겹치는 사례가 반복됐다 — 정보는 상단 중앙/하단으로.
- **링크 깨짐.** 상대경로·폴더명 확인. 워크트리/배포 폴더 등 **사본을 여러 곳에 유지한다면** 같은
  변경을 모든 사본에 동기화한다.
- **글꼴 미적용.** 22개 파일 전체에 `@font-face`를 주입하고 `font-family` 스택을 통일해야 한다.
