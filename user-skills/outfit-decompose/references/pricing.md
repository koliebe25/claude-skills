AI 앱은 **버튼 하나가 돈**입니다. 사용자가 모르고 누르게 두면 신뢰를 잃습니다.

> 구현 전에 각 사의 가격 페이지를 다시 확인하세요.

## 놓치기 쉬운 두 가지

**OpenAI는 입력도 과금됩니다.** 참조 사진(이미지 토큰 $8/1M)과 프롬프트(텍스트 $5/1M)가
따로 계산됩니다. 출력 이미지 가격만 더하면 실제보다 싸게 나옵니다. 이미지 1장당
약 **$0.012**를 더하세요.

**OpenAI는 세로와 정방의 단가가 다릅니다.** 착용컷과 제품컷을 나눠 계산해야 합니다.
Gemini는 비율과 무관하게 같습니다.

## 분석 비용 추정

토큰 수를 추정해 곱합니다. 실측 기준 입력 약 2,500 / 출력 약 3,000 토큰입니다.
(시스템 프롬프트 + 축소된 사진, 아이템 7~9개의 상세 JSON)

```ts
const ANALYSIS_TOKENS = { input: 2500, output: 3000 };

function analysisCostUsd(provider) {
  const rate = TOKEN_RATES[provider];
  return (ANALYSIS_TOKENS.input * rate.input) / 1_000_000
       + (ANALYSIS_TOKENS.output * rate.output) / 1_000_000;
}
```

## 원화 환산

환율을 상수로 두고 환경변수로 덮어쓸 수 있게 하세요. 화면에 **기준 환율을 함께 표시**해야
사용자가 언제 기준인지 압니다.

```ts
export const USD_KRW = Number(process.env.NEXT_PUBLIC_USD_KRW) || 1414;

export function formatKrw(usd) {
  return `₩${Math.round(usd * USD_KRW).toLocaleString("ko-KR")}`;
}
```

## 어디에 표시할 것인가

돈이 나가는 지점마다 사전에 보여줍니다.

| 위치 | 표시 |
|---|---|
| 업로드 화면 | `분석 예상 비용 약 ₩19` |
| 화질 토글 | 칩에 컷당 단가 직접 표기 — `스탠다드 ₩95` / `프로 ₩189` |
| 생성 버튼 앞 | 착용컷·제품컷 나눈 내역 + 합계 + **다른 화질로 바꿨을 때 금액** |
| 결과 화면 | 실제로 성공한 컷 기준 사용 비용 |
| 재생성 버튼 | 컷당 추가 비용 |

생성 직전 화면 예시:

```
예상 비용                    ₩947
  착용컷 1장                 ₩189
  제품컷 4장                 ₩758
  프로 화질 · Gemini 기준 ($0.670, 1 USD = ₩1,414).
  스탠다드로 바꾸면 ₩474 입니다.
```

**다른 화질의 금액을 함께 보여주는 것**이 특히 유용합니다. 사용자가 토글을 눌러보지 않고도
비교해 결정할 수 있습니다.

## 실제 사용 비용

결과 화면에는 **성공한 컷만** 세어 표시하세요. 실패한 요청은 과금되지 않습니다.

```ts
const spentUsd =
  (heroImage ? imageCostUsd(provider, quality, true) : 0) +
  imageCostUsd(provider, quality, false) * doneItemCount;
```

## 표기 원칙

항상 **"예상"·"약"**으로 씁니다. 공식 단가는 정확하지만 분석의 토큰 수는 추정이라
실제 청구액과 몇 원 차이가 납니다. 확정 금액처럼 보이면 오히려 신뢰를 잃습니다.
