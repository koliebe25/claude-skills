# Screenwriting — 숏폼 드라마 대본 스킬

기획·캐릭터 바이블을 바탕으로 30초 내외(25~35초) 회차의 대본을 집필한다. 비주얼·영상 에이전트가 컷으로 분해할 수 있도록 씬을 구조화하는 것이 핵심이다.

## 입력
- `_workspace/01_story-architect_planning.md` — 회차 비트·캐릭터 바이블·톤을 반드시 준수
- story-architect의 메시지(보강 설정)

## 산출물 구조 (`_workspace/02_scriptwriter_script.md`)

회차 → 씬 계층으로 작성한다.

```
# {N}화 — {회차 제목}
**훅(0~2초):** {도입 훅 묘사 — 즉시 갈등/충격/도발}

## [씬 N-1] 장소 / 시간(낮·밤) | 등장인물
- 지문: {행동·상황 묘사 — 시각적으로}
- 대사:
  - 인물A: "..."
  - 인물B: "..."
- 연출: {앵글/감정/속도 등 연출 지시}

## [씬 N-2] ...

**클리프행어:** {회차 말미 다음 화를 부르는 장치}
```

## 작성 원칙
- **숏폼 페이싱:** 회차 30초 내외 ≈ 4~7씬, 매우 짧은 호흡. 대사는 짧고 직선적, 설명 대신 행동·갈등
- **훅 & 클리프행어 필수:** 모든 회차에 강력한 첫 1~2초 훅과 말미 클리프행어를 명시적으로 라벨링. 첫 씬은 도입·설명 없이 즉시 갈등·충격·도발로 열고, 가장 센 대사/상황을 맨 앞에 배치
- **캐릭터 말투 일관성:** 캐릭터 바이블의 말투를 준수. 의문이 생기면 임의 결정 금지 → story-architect에 확인
- **컷 친화 구조:** 각 씬에 장소·시간·등장인물·주요 동작·감정을 명시해 visual-director가 컷으로 옮기기 쉽게 한다
- **기획 이탈 금지:** 회차 비트를 벗어날 필요가 있으면 SendMessage로 협의 후 반영

## 후속 작업
이전 대본이 있으면 읽고, 피드백 대상 회차/씬만 수정한다. 캐릭터 말투·설정 변경은 기획과 어긋나지 않도록 story-architect와 동기화한다.
