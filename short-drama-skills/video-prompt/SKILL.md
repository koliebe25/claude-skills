# Video Prompt — 숏폼 드라마 영상 프롬프트 스킬

비주얼 컷을 움직임·카메라·전환이 있는 영상 샷으로 변환하고, 회차 타임라인과 영상 생성 프롬프트를 만든다. 캐릭터 일관성을 유지한 채 정지 컷에 생명을 부여하는 것이 핵심이다.

## 입력
- `_workspace/03_visual-director_character-sheets.md` — 캐릭터 외형 앵커
- `_workspace/03_visual-director_image-prompts.md` — 컷 프롬프트(키프레임)
- `_workspace/02_scriptwriter_script.md` — 페이싱·감정 곡선

## 산출물 1: 샷 리스트 + 타임라인 (`_workspace/04_video-producer_shotlist.md`)

```
# {N}화 타임라인 (총 길이: {초}s / 목표 30초 내외, 25~35초)
| 샷 | 기준 컷 | 길이(s) | 카메라 무빙 | 동작 요약 | 사운드/자막 큐 | 전환 |
|----|--------|--------|-----------|---------|-------------|------|
| N-1 | 1-1-1 | 3 | 천천히 줌인 | ... | BGM in / 자막"..." | 컷 |
```
- 샷 길이 합이 회차 목표(30초 내외, 25~35초)에 맞는지 합산·검증. **표기 총 길이 = 샷별 길이 열의 합**이 정확히 일치하도록 반드시 재검산

## 산출물 2: 영상 생성 프롬프트 (`_workspace/04_video-producer_video-prompts.md`)

```
### [{회차}-{샷}] 기준 컷 {컷ID}
- 길이: {초}s
- 영상 프롬프트(EN): {캐릭터 외형 앵커 + 동작(motion) + 카메라 무빙 + 속도 + 9:16}
- 영상 프롬프트(KO): {동일}
- 모드: image-to-video(기준 컷 이미지 사용) / text-to-video
- 사운드: {BGM/효과음/대사 보이스}
- 자막: {타이밍·텍스트}
```

## 작성 원칙
- **컷 기준 + 움직임 부여:** 컷을 키프레임으로 삼아 동작·카메라 무빙을 더한다 (image-to-video 우선)
- **캐릭터 앵커 유지:** 영상 프롬프트에도 외형 앵커를 유지해 샷 간 드리프트 방지
- **숏폼 리듬:** 짧은 샷·빠른 전환, 첫 샷 강한 훅, 말미 클리프행어 샷. 회차 총 길이 30초 내외(25~35초) 준수 = 대략 6~10샷, 평균 3~4초/샷
- **제작 현실성:** 생성 모델의 클립 길이·일관성 한계를 고려해 긴 동작은 샷으로 분할하고 폴백을 제시. 워크플로우는 글로벌 스킬 `higgsfield-content-factory` 참조 가능
- **타임라인 검증:** 샷 길이 합이 목표를 크게 벗어나면 압축 또는 회차 분할 제안

## 후속 작업
이전 산출물이 있으면 읽고 수정 대상 샷만 갱신한다. 캐릭터 앵커나 컷이 바뀌면 영향받는 샷 프롬프트에 반영한다.
