# Visual Prompt — 숏폼 드라마 비주얼/이미지 프롬프트 스킬

대본과 캐릭터 바이블을 세로 9:16 컷 이미지 프롬프트로 변환한다. **캐릭터 외형이 모든 컷에서 동일하게 유지되는 것**이 최우선 품질 기준이다.

## 입력
- `_workspace/01_story-architect_planning.md` — 캐릭터 외형 묘사
- `_workspace/02_scriptwriter_script.md` — 씬·감정·동작

## 산출물 1: 캐릭터 레퍼런스 시트 (`_workspace/03_visual-director_character-sheets.md`)

캐릭터별로 **외형 앵커(고정 묘사 블록)**를 한 번 정의한다. 이 블록을 이후 모든 컷 프롬프트에 그대로 삽입한다.

```
## {캐릭터명} — 외형 앵커
- 핵심 묘사(EN): {age, hair, face, body, signature outfit, distinguishing features}
- 핵심 묘사(KO): {동일 내용}
- 고정 키워드: {매 컷 반드시 포함할 키워드 목록}
```

## 산출물 2: 컷별 이미지 프롬프트 (`_workspace/03_visual-director_image-prompts.md`)

대본의 각 씬을 9:16 컷으로 분해한다.

```
### [{회차}-{씬}-{컷}] {한 줄 설명}
- 등장: {캐릭터명 + 외형 앵커 키워드 삽입}
- 구도/앵글: {클로즈업/미디엄/와이드, 카메라 앵글, 세로 프레임 여백}
- 조명/분위기: {시간대, 광원, 무드}
- 프롬프트(EN): {subject + character anchor + composition + lighting + style + 9:16 파라미터}
- 프롬프트(KO): {동일}
- 비고: {가정·주의}
```

## 작성 원칙
- **일관성 앵커 강제:** 등장 캐릭터의 외형 앵커 키워드를 모든 컷 프롬프트에 반드시 포함 → 드리프트 방지
- **세로 9:16 최적화:** 구도·여백·자막 공간을 세로 프레임 기준으로. `--ar 9:16` 등 비율 파라미터 명시
- **대본 충실:** 컷은 씬의 장소·감정·동작을 정확히 반영. 컷 누락 없이 1:1 이상 매핑
- **도구 친화:** 미드저니/이미지 모델에 바로 투입 가능한 구조. 필요 시 글로벌 스킬 `mj-prompt-guide-by-blue`, `aitoon` 참조
- 씬당 컷 수는 대사·동작 전환에 맞춰 분할 (정지 컷 1~3개/씬 권장)

## ⚠ 앵커 전체 문자열 강제 체크리스트 (필수 — 반복 드리프트 방지)

> **왜:** 약칭·일부 토큰만 넣으면 컷 간 얼굴이 미세하게 달라진다(드리프트). 특히 얼굴 식별 토큰(입술·눈·흉터·점)이 빠지면 생성 모델이 다른 인물처럼 그린다. 과거 검수에서 단축형 앵커가 반복 적발됐으므로, 작성 단계에서 아래 체크리스트로 자가 검증한다.

1. **산출물 상단에 캐릭터별 "필수 토큰 목록"을 명시한다.** 각 캐릭터의 외형 앵커에서 절대 빠지면 안 되는 식별 토큰(나이/키/얼굴형/눈/입술/헤어/흉터·점 등 + 시그니처 의상)을 나열.
2. **얼굴이 노출되는 모든 컷의 EN 프롬프트에 해당 캐릭터의 필수 토큰을 약칭 없이 전체 문자열로 삽입한다.** "(앞과 동일)" 같은 참조 표기 금지 — 각 컷에 실제 문자열을 반복 기입.
3. **예외는 손·소품·신체 일부만 보이고 얼굴이 미노출인 전용 인서트 컷뿐.** 이 경우 비고에 "인서트, 얼굴 미노출"을 반드시 명시한다.
4. **저장 전 자가 검증:** 캐릭터별 필수 토큰이 "얼굴 노출 컷 수"와 동일한 횟수로 등장하는지 카운트로 확인(예: 서아 얼굴 컷 21개 → `plump lips` 21회). 불일치 시 누락 컷을 보강한 뒤 저장.

## 후속 작업
이전 산출물이 있으면 읽고 수정 대상 컷/캐릭터만 갱신한다. **외형 앵커를 바꾸면 그 캐릭터가 등장하는 모든 컷 프롬프트에 일괄 반영**한다(부분만 바꾸면 드리프트 발생).
