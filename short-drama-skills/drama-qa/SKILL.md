# Drama QA — 숏폼 드라마 정합성 검수 스킬

핵심은 "각 산출물이 있는가"가 아니라 **"단계 간 경계면이 일치하는가"**다. 두 단계의 산출물을 동시에 열어 shape을 비교하여 드리프트·누락·모순을 찾는다.

## 검수 경계면 (각각 두 파일을 나란히 비교)

### 1. 기획 ↔ 대본
- 회차 비트가 대본에 반영됐는가 / 캐릭터 동기·말투 일관 / 톤 유지

### 2. 대본 ↔ 비주얼
- 대본의 **모든 씬이 컷으로 분해**됐는가 (씬 목록 vs 컷 목록 1:1 매칭, 누락 탐지)
- 컷이 씬의 장소·감정·동작과 일치하는가

### 3. 비주얼 ↔ 영상
- **모든 컷이 샷에 반영**됐는가 (컷 목록 vs 샷 목록 매칭)
- 캐릭터 외형 앵커가 컷·샷에서 동일하게 유지되는가

### 4. 캐릭터 연속성 (최우선)
- 캐릭터 바이블의 외형·이름·관계가 기획→대본→비주얼→영상 전 단계에서 일관된가
- 외형 앵커 키워드 드리프트(머리색·의상·나이 변화 등) 탐지

### 5. 플랫폼 규격
- 세로 9:16 / 회차 30초 내외(25~35초, 샷 길이 합) / 강력한 첫 1~2초 훅 / 말미 클리프행어가 모든 회차에 존재하는가

## 산출물 (`_workspace/05_qa-reviewer_report.md`)

```
## [경계면명] (회차/씬 단위)
- 판정: PASS | FIX | BLOCK
- 발견: {파일A 항목} vs {파일B 항목} 의 구체적 불일치
- 수정 지시: {담당 에이전트} — {구체적 수정 방향}
```
- **PASS:** 일치 / **FIX:** 부분 수정으로 해결 / **BLOCK:** 상위 단계 수정 필요한 구조적 불일치

## 작성 원칙
- **점진적 검수:** 단계 산출물이 나올 때마다 직전 단계와 즉시 교차 비교 (전체 완성 후 1회가 아님)
- **shape 비교:** 목록 대 목록(씬↔컷, 컷↔샷)을 나란히 놓고 매핑 누락을 센다
- **객관적 정합성:** 취향이 아닌 누락·모순·드리프트·규격 위반만 지적
- **직접 통신:** FIX/BLOCK은 담당 에이전트에게 SendMessage로 바로 전달, 리더에게 요약 보고
- **회귀 방지:** 재검수 시 직전 수정 부분만 재검증하되, 그 변경이 다른 경계면을 깨지 않았는지 함께 확인

## 후속 작업
이전 리포트가 있으면 읽고, 수정된 부분만 재검증한다. 동일 FIX가 2회 이상 반복되면 구조적 원인(스킬/기획 차원)을 리더에게 제안한다.
